# КРЕПОСТЬ: правила ключа и подделки

## Ключ

1. Ключ, вставленный в переписку, — засвеченный ключ. Его нужно отозвать
   и выпустить новый: GitHub → Settings → Developer settings → Personal
   access tokens → Regenerate.
2. Новый ключ входит ТОЛЬКО в скрытый ввод `bootstrap.sh` (read -s,
   ввод не отображается и не попадает в файлы, argv, логи, .git/config).
3. Никакой скрипт комплекта не пишет ключ на диск и не печатает его.
   Пуш идёт через одноразовый credential helper внутри одного процесса.

## Подделка

1. Руками счётчик в MAP.md — ЗАПРЕЩЁН. Числа живут только маркерами
   `<!--c:имя-->N<!--/c-->`, вписывает их генератор.
2. `drift` пересчитывает всё из живого публичного API и сравнивает.
   Расхождение = exit 1 = красный CI.
3. CI (meta-drift) стоит на push и pull_request; бот (meta-map) пересобирает
   карту на main и ночью по расписанию — карта всегда живая.

## Граница

Единственное действие, которое делает человек, — вставить новый ключ в
скрытый промпт. Всё остальное: создание репо, вселение, CI, ночная
пересборка карты — делает kit. Пуша без ключа не существует; ключа вне
руках владельца не существует. Это не каприз — это конструкция дома.
